1. MỞ KHO GAME TRÊN MÁY TÍNH
- Giải nén toàn bộ tệp ZIP trước khi mở.
- Mở thư mục kho-game-be-thong-thai-2026.
- Nhấp đúp MO_KHO_GAME.bat hoặc mở index.html bằng Chrome/Cốc Cốc.

2. CẬP NHẬT WEBSITE GITHUB PAGES
- Sao chép nội dung trong thư mục này vào thư mục Repository kho-game-be-thong-thai-2026 trên máy tính.
- Giữ nguyên cấu trúc index.html, games và assets.
- Mở GitHub Desktop, kiểm tra các thay đổi, nhập nội dung Commit rồi chọn Commit to main.
- Chọn Push origin để gửi thay đổi lên GitHub.
- Chờ GitHub Pages cập nhật rồi mở lại website để kiểm tra.
- Đường link và mã QR cũ vẫn dùng được nếu không đổi địa chỉ Repository/website.

3. DANH SÁCH TRÒ CHƠI
- 25 trò chơi HTML nằm trong thư mục games.
- 21 trò chơi liên kết: giữ lại 9 liên kết cũ và thêm đủ 12 liên kết mới theo danh sách Word.
